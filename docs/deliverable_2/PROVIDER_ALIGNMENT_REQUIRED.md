# Alineación de proveedor requerida

Texto recibido:

> Aplicación efectivamente desplegada y accesible en Google Cloud Platform...

Estado del proyecto:

- implementación y IaC objetivo: AWS;
- runtime: ECS/Fargate;
- imágenes: ECR;
- HTTPS/WSS: CloudFront + ALB;
- discovery: Cloud Map;
- datos custom: EFS;
- secretos: Secrets Manager;
- logs/métricas: CloudWatch.

Por tanto, **evidencia AWS no demuestra literalmente despliegue en Google Cloud Platform**. Antes de la entrega debe existir una aprobación explícita del cambio de proveedor o una redacción aceptada como “plataforma desplegada y operativa en la nube pública (AWS)”.

No modificar ni ocultar esta diferencia en el informe final.
